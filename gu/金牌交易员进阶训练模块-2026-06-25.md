# 金牌交易员进阶训练模块

> 日期：2026-06-25  
> 定位：把基础 SOP 升级为概率、节奏、案例和行为训练系统。  
> 边界：本文用于训练判断力，不用于鼓励重仓、追涨或频繁交易。

## 0. 核心差距

基础交易者靠规则避免犯大错。

优秀交易员在规则之上，还会判断：

```text
市场处于什么情绪阶段？
这只票是主线龙头、跟风，还是补涨？
今天放量是换手、承接，还是出货？
涨停封住后，次日溢价概率高不高？
我现在是在执行计划，还是被情绪驱动？
```

训练目标：

```text
先做到不亏大钱。
再做到看懂节奏。
最后才追求提高胜率和收益。
```

## 1. 市场情绪周期模块

短线不是每天都适合做。先判断市场情绪阶段，再决定进攻还是防守。

### 阶段一：冰点

特征：

```text
涨停数量少。
连板高度低。
高位股补跌。
热门板块持续性差。
昨天涨停今天低开多。
```

动作：

- 不打板。
- 不追高。
- 只观察低位企稳和防守方向。
- 仓位 0%-30%。

### 阶段二：修复

特征：

```text
指数止跌。
高位亏钱效应缓和。
前期强势股不再大跌。
开始出现新题材试探。
```

动作：

- 小仓试错。
- 优先低位首板、强趋势回踩。
- 不重仓。
- 仓位 20%-40%。

### 阶段三：主升

特征：

```text
主线清晰。
龙头持续创新高。
板块内多只股票共振。
成交额放大。
涨停数量增加。
断板后亏钱效应不大。
```

动作：

- 可以做主线趋势跟随。
- 只做龙头或强势二线。
- 回踩确认优先。
- 仓位 40%-60%，新手不超过 50%。

### 阶段四：高潮

特征：

```text
同板块大面积涨停。
后排跟风也快速上涨。
媒体和社交平台热度很高。
个股高开越来越多。
成交额极大，分歧变重。
```

动作：

- 不追后排。
- 持仓可以分批止盈。
- 新开仓降低仓位。
- 仓位开始收缩。

### 阶段五：退潮

特征：

```text
龙头放量滞涨。
涨停股开板增多。
昨日涨停次日低开。
板块内高位股集体回落。
跌停或大阴线增加。
```

动作：

- 停止新开仓。
- 持仓破位先处理。
- 不做亏损补仓。
- 仓位降到 0%-30%。

## 2. 涨停和炸板案例库

想吃涨停，必须研究涨停后的表现，而不是只看当天涨没涨停。

### 案例分类

#### A 类：强封涨停

特征：

```text
快速封板。
封单稳定。
开板次数少。
成交逐渐缩小。
板块同步走强。
```

次日预期：

- 通常有溢价。
- 可观察高开后是否继续强。
- 不追过高开盘。

#### B 类：换手涨停

特征：

```text
盘中有分歧。
开板但能快速回封。
成交较大。
尾盘封单稳定。
```

次日预期：

- 如果板块继续强，可能继续上冲。
- 如果低开或弱开，要小心。

#### C 类：烂板

特征：

```text
反复开板。
封单越来越少。
成交巨量。
尾盘勉强封住。
板块支撑一般。
```

次日预期：

- 容易低开或冲高回落。
- 新手不追。
- 持仓者次日优先看开盘承接。

#### D 类：炸板失败

特征：

```text
冲到涨停附近。
没有封住。
放巨量回落。
收盘远离涨停价。
```

次日预期：

- 风险高。
- 可能低开。
- 持仓者优先减仓或退出。


## 3. 量价关系训练库

成交量要结合价格位置看。

### 量价组合一：低位放量上涨

含义：

```text
可能有资金进场。
如果突破平台，值得观察。
```

动作：

- 不追第一根大阳。
- 等回踩不破。
- 看第二天是否有承接。

### 量价组合二：上涨放量，回调缩量

含义：

```text
健康。
上涨有人买，回调卖压不大。
```

动作：

- 适合回踩确认。
- 可以列入候选。

### 量价组合三：高位爆量滞涨

含义：

```text
分歧极大。
可能有人出货。
```

动作：

- 不追。
- 持仓者减仓或提高止盈。

### 量价组合四：下跌放量

含义：

```text
卖压强。
风险释放中。
```

动作：

- 不抄底。
- 等止跌和重新站上均线。

### 量价组合五：缩量上涨

含义：

```text
可能是控盘强，也可能是跟风不足。
需要看位置和板块。
```

动作：

- 低位缩量上涨可观察。
- 高位缩量上涨谨慎追。

## 4. 交易行为评分表

优秀交易员每天给自己的行为打分，不只看盈亏。

满分 100 分。

```text
是否按计划交易：20 分
是否没有追高：15 分
是否没有亏损补仓：15 分
是否按止损执行：20 分
是否控制仓位：15 分
是否完成复盘：10 分
是否控制情绪：5 分
```

扣分规则：

- 临时买计划外股票：扣 20 分。
- 亏损补仓：扣 20 分。
- 不执行止损：扣 30 分。
- 超过计划仓位：扣 15 分。
- 卖飞后追回：扣 15 分。
- 因为群消息、短视频、热搜交易：扣 20 分。

每日记录：

```text
日期：
今日交易：
是否计划内：
是否追高：
是否补仓：
是否止损：
是否超仓：
是否复盘：
情绪状态：
今日行为分：
最大错误：
明日只改一件事：
```

评价标准：

```text
90 分以上：纪律优秀。
80-90 分：可继续小仓实战。
70-80 分：减少交易，只做一只。
70 分以下：暂停新开仓，复盘错误。
```

## 5. 主线、龙头和跟风识别

短线不要只看个股，要看它在板块中的地位。

### 主线

特征：

```text
板块持续 3 天以上活跃。
成交额不断放大。
多只股票同步上涨。
龙头不断创新高。
消息、产业、业绩能相互印证。
```

### 龙头

特征：

```text
涨得最早。
涨得最强。
调整时最抗跌。
板块反弹时最先动。
成交额和关注度最高。
```

### 跟风

特征：

```text
龙头涨很多后才启动。
涨幅落后。
板块一弱就先跌。
成交量不稳定。
```

动作：

- 新手尽量只看龙头和强势二线。
- 不追后排跟风。
- 板块高潮时不要买补涨后排。

## 6. 进阶训练计划

### 第 1 周：只练纪律

任务：

- 每天按 SOP 记录三个时间点。
- 不买计划外股票。
- 不补仓。
- 只做一只票。

### 第 2 周：练量价

任务：

- 每天记录 3 只强势股的量价关系。
- 判断是放量上涨、放量滞涨、缩量回调还是下跌放量。
- 次日验证判断。

### 第 3 周：练涨停案例

任务：

- 每天记录 3 个涨停股。
- 标注强封、换手、烂板、炸板失败。
- 次日看溢价。

### 第 4 周：练情绪周期

任务：

- 每天记录市场阶段。
- 判断冰点、修复、主升、高潮、退潮。
- 对照自己是否应该进攻。

## 7. 最小训练闭环

每天只做四件事：

```text
1. 判断市场情绪阶段。
2. 记录 1 个涨停或炸板案例。
3. 记录 1 个量价案例。
4. 给自己行为打分。
```

坚持 20 个交易日后，你会比只看股票推荐进步得更快。

## 8. 和现有 SOP 的关系

```text
买股 SOP：告诉你今天怎么做。
三时间点盯盘 SOP：告诉你盘中怎么看。
交易记录模板：告诉你怎么记录结果。
金牌交易员训练模块：告诉你怎么提高判断力。
```

顺序不能反：

```text
先会守纪律，再练进攻。
先会止损，再想涨停。
先会记录，再谈盘感。
```
