# 买股 SOP

> 日期：2026-06-24  
> 定位：把“每天怎么买”压缩成固定流程。  
> 边界：SOP 用于减少冲动和控制亏损，不保证收益，不替代持牌投顾意见。

## 0. 核心结论

不是每天 9 点直接下条件单就完事。

正确流程是：

```text
前一晚写计划 -> 盘前复核风险 -> 9:25 后看开盘状态 -> 符合条件才保留条件单 -> 不符合条件撤销或不下单
```

A 股通常 T+1，当天买入后当天不能卖出。  
因此买入前必须假设：

```text
如果今天买入后立刻跌破止损，我当天可能卖不出去，只能次日处理。
```

所以 SOP 的重点不是“跌破了怎么办”，而是“买之前就把会跌破的概率和损失压小”。

## 1. 前一晚：只做计划，不下情绪单

收盘后完成：

```text
候选股票：
候选类型：回调 / 突破 / 反转 / 红利
巴菲特标签：投资级 / 交易级 / 观察级 / 禁入级
是否看懂主营业务：是 / 否
买入触发条件：
计划买入区间：
止损价：
目标价：
目标价来源：
计划仓位：
不买条件：
次日若低开 5% 是否可承受：是 / 否
```

硬规则：

- 没有止损价，不进入明日计划。
- 没有不买条件，不进入明日计划。
- 巴菲特标签为观察级或禁入级，不进入明日计划。
- 交易级股票不能用长期价值投资逻辑扛亏。
- 买入价到止损价超过 8%-10%，不进入明日计划。
- 近 10 日平均振幅大于 6%，新手默认不做。

## 2. 08:50：盘前风控

开盘前检查：

```text
公司公告：无重大利空 / 有重大利空
监管问询：无未解决问询 / 有未解决问询
减持解禁：无明显压力 / 有明显压力
财报预告：无异常 / 低于预期 / 高于预期
大盘环境：强 / 震荡 / 弱
板块状态：主线增强 / 正常轮动 / 明显退潮
龙头状态：未破位 / 放量滞涨 / 已破位
```

直接取消买入计划：

- 有重大利空。
- 板块龙头明显破位。
- 大盘明显弱势且放量下跌。
- 候选股高开预期过强，可能破坏风险收益比。

## 3. 09:00-09:25：不要急着下买入条件单

9 点可以做准备，但不要机械地下买单。

允许做：

- 打开交易软件。
- 核对候选股、买入区间、止损价。
- 设置价格提醒。
- 准备条件单草稿。

不允许做：

- 因为集合竞价高开就追。
- 因为群消息临时加股票。
- 因为怕踏空把买入价上移。

## 4. 09:25-09:35：开盘过滤

集合竞价结束后检查：

```text
是否高开超过 3%-5%？
是否直接远离计划买入区？
是否板块整体走强？
是否龙头同步走强？
是否出现异常放量或砸盘？
```

处理：

- 高开过多且不回踩：不买。
- 低开但未破关键支撑：观察，不急买。
- 直接跌破计划支撑：取消买入。
- 符合计划区间且板块正常：可以保留条件单或等待确认。

## 5. 买入条件单怎么设

条件单只用于执行计划，不用于替代判断。

### 回调买入

```text
触发条件：回踩计划买入区间不破，且没有放量下杀。
下单方式：限价买入。
第一笔仓位：3%-5%。
```

### 突破买入

```text
触发条件：收盘或盘中有效站上突破位，成交量配合。
新手优先：突破当天不追，等回踩突破位不破。
第一笔仓位：3%-5%。
```

### 不建议新手用的条件单

- 开盘自动追涨条件单。
- 涨幅触发买入单。
- 突破即市价买入单。
- 高波动股的市价条件单。

## 6. T 日买入后盘中跌破止损怎么办

这是 A 股 T+1 的核心问题。

如果当天买入后盘中跌破止损：

```text
1. 不补仓。
2. 不把止损价下移。
3. 标记为 T+1 风险单。
4. 记录跌破原因：大盘 / 板块 / 个股 / 假突破 / 买点错误。
5. 收盘前复核是否仍在止损价下方。
```

当天不能卖时，不能做的事：

- 不能因为卖不掉就安慰自己“做长线”。
- 不能加仓摊低成本。
- 不能取消原止损。
- 不能把止损改成更低位置。

## 7. 次日风险处理

T 日买入，T 日盘中或收盘跌破止损，T+1 按风险单处理。

### 情况 A：次日低开在止损价下方

处理：

```text
开盘后优先卖出或减仓。
如果流动性正常，用限价单贴近可成交价处理。
如果快速下跌，接受滑点，先控制风险。
```

### 情况 B：次日高开回到止损价上方

处理：

```text
不立刻幻想反转。
观察 15-30 分钟是否重新站稳关键位。
站不稳，减仓或退出。
重新站稳且板块转强，可按原计划继续观察，但不能加仓。
```

### 情况 C：次日继续跌停或流动性不足

处理：

```text
继续挂风险处理单。
停止同板块新开仓。
把该股记录为流动性风险案例。
后续降低同类股票仓位。
```

## 8. 为什么更推荐尾盘确认

对新手而言，尾盘买入比早盘追高更稳。

尾盘买入优点：

- 当天走势基本成型。
- 更容易判断是否站上关键位。
- 能减少盘中假突破。
- 能更清楚评估板块是否退潮。

尾盘买入条件：

```text
14:30 后仍站上关键支撑或突破位。
成交量符合预期。
大盘没有明显跳水。
板块龙头没有破位。
次日低开 5% 仍能承受。
```
