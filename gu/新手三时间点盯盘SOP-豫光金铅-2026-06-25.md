# 新手三时间点盯盘 SOP：豫光金铅

> 日期：2026-06-25  
> 适用场景：已持有豫光金铅 600531 一手，次日做短线观察和风险处理。  
> 边界：本文是交易流程训练，不保证收益，不替代持牌投顾意见。

## 0. 你明天的总原则

你明天不是去找新股，也不是去加仓。

你明天只有一个任务：

```text
管理好手里这一手豫光金铅。
```

默认动作：

```text
不买新股。
不加仓豫光金铅。
上午只观察。
下午 15:25 前后再决定拿不拿、卖不卖。
```

为什么这样做：

- 你是 2 万资金，新手阶段不适合同时处理太多股票。
- 豫光金铅是高波动短线票，涨得快，跌起来也快。
- A 股通常 T+1，当天买入后当天不能卖，所以不能早盘乱加仓。
- 你现在最重要的是练纪律，不是追求一天赚很多。

## 1. 明天只看这几个价格

先把价格写死，盘中不要临时改。

```text
参考收盘价：15.76
警戒线：14.80
硬止损线：14.44
第一止盈观察：16.50
涨停附近：约 17.34
强压力区：17.50 附近
```

这些价格是什么意思：

### 15.76：参考强弱线

这是你截图里的收盘价。

如果股价在 15.76 上方，说明市场愿意给它比昨天收盘更高的价格，短线偏强。

如果股价一直在 15.76 下方，说明昨天追进去的人短线没有优势，要谨慎。

### 14.80：警戒线

这是上一根强阳线的开盘价附近。

如果跌破 14.80，说明强势开始变弱，但不一定马上死。  
它是提醒你认真看盘的位置。

### 14.44：硬止损线

这是上一交易日低点附近。

如果跌破 14.44，说明上一根强阳线基本失败。  
这时候不要再幻想，也不要补仓。

### 16.50：第一止盈观察位

如果涨到 16.50 附近但冲不动，说明短线已经有利润，可以考虑卖掉一手锁利润。

### 17.34：涨停附近

如果它冲到涨停附近，你不是马上卖，而是看能不能封住。

### 17.50：强压力区

前面 K 线有过 17.50 附近的高点，这里容易有套牢盘和止盈盘。

如果冲到这里但封不住，优先卖。

## 2. 时间点一：09:15-09:35

### 这个时间段的目标

这个时间段只回答一个问题：

```text
今天开局是强、正常、弱，还是破位？
```

不要急着买。  
不要加仓。  
不要因为红了就兴奋。

### 你需要打开什么

打开交易软件，至少看三个页面：

```text
1. 豫光金铅分时图
2. 有色板块涨跌
3. 上证指数
```

如果软件能看盘口，也可以看买卖盘，但新手先不用复杂化。

### 第一步：看开盘位置

用昨天收盘价 15.76 做参考。

```text
高开到 16.20 以上：偏强，但不能追。
开在 15.50-16.20：正常，继续观察。
低开到 14.80-15.50：偏弱，但还没坏。
低开跌破 14.80：进入风险观察。
低开跌破 14.44：准备止损。
```

为什么不能高开就追：

高开代表有人抢，但也可能代表有人借高开卖。  
新手最容易在高开的时候冲进去，然后被高开低走套住。

### 第二步：看开盘 5 分钟怎么走

看 09:30-09:35。

强的样子：

```text
开盘后不快速跌破开盘价。
股价能站在 15.76 上方。
回落时速度慢。
有色板块不是绿的。
```

弱的样子：

```text
高开后快速下跌。
跌回 15.76 下方。
跌破 14.80。
有色板块同步走弱。
```

### 第三步：写一句结论

你只写四选一：

```text
强：站上 15.76，板块不弱。
正常：在 14.80-15.76 之间震荡。
弱：跌破 14.80，但没破 14.44。
破位：跌破 14.44。
```

### 这个时间段的动作

```text
强：继续拿，不加仓。
正常：继续观察，不操作。
弱：准备下午或触发条件处理。
破位：按止损处理。
```

### 这个时间段禁止做什么

```text
禁止加仓。
禁止追高。
禁止看到红了就买第二手。
禁止跌了补仓。
禁止把 14.44 止损线往下改。
```

## 3. 时间点二：09:35-10:00

### 这个时间段的目标

这个时间段只回答一个问题：

```text
开盘那波之后，有没有资金继续接？
```

开盘强不算真正强。  
开盘后能不能站住，才重要。

### 第一步：看是否高开低走

高开低走的样子：

```text
开盘高于昨天收盘。
开盘后冲一下。
很快跌回开盘价下方。
成交明显放大。
股价被分时均价线压住。
```

这说明可能有人借高开卖。

如果出现这种走势：

```text
不加仓。
不幻想涨停。
跌破 14.80 后要提高警惕。
```

### 第二步：看是否回踩不破

健康的样子：

```text
没有大幅高开。
回踩时没有放量砸盘。
14.80 没破。
重新拉回 15.76 附近或上方。
```

这说明短线还有承接。

如果出现这种走势：

```text
继续拿。
不加仓。
尾盘再决定。
```

### 第三步：看板块是否配合

你要看有色板块，不只看豫光金铅自己。

板块配合的样子：

```text
有色板块红盘。
板块内强股没有集体跳水。
豫光金铅不是一个人硬撑。
```

板块不配合的样子：

```text
有色板块翻绿。
同板块强股冲高回落。
豫光金铅放量但涨不上去。
```

板块不配合时，不要加仓。

### 第四步：看是否冲涨停

如果 09:35-10:00 冲到 17 附近，你要看能不能封板。

能拿的涨停：

```text
冲板速度快。
封单稳定。
开板次数少。
成交逐渐缩小。
板块也强。
```

该卖的涨停：

```text
反复开板。
封单越来越少。
成交突然放巨量。
板块不跟。
冲到涨停附近又快速回落。
```

你只有一手，看到反复开板，不要贪。

### 这个时间段的动作

```text
站稳 15.76：继续拿。
在 14.80-15.76 之间：观察。
跌破 14.80 且拉不回：准备处理。
跌破 14.44：卖出认错。
冲 17.20-17.34 但封不住：卖。
封住涨停且封单稳定：继续拿。
```

## 4. 时间点三：14:30-15:25

### 这个时间段的目标

这是你最重要的操作时间。

这个时间段只回答一个问题：

```text
收盘前资金还认不认这只票？
```

早盘强，尾盘弱，不算强。  
尾盘还能站住，才更有参考意义。

### 第一步：看是否尾盘跳水

尾盘跳水的样子：

```text
14:30 后快速下跌。
跌破日内平台。
成交放大。
有色板块也回落。
收盘前拉不回来。
```

如果尾盘跳水：

```text
不要恋战。
跌破 14.80 且收不回，考虑卖。
跌破 14.44，必须按止损处理。
```

### 第二步：看是否站稳关键位

关键位就是：

```text
15.76
14.80
14.44
```

判断：

```text
收在 15.76 上方：偏强，可以继续拿。
收在 14.80-15.76：一般，谨慎持有。
收在 14.80 下方：偏弱，考虑卖出。
收在 14.44 下方：破位，卖出认错。
```

### 第三步：看是否接近涨停

如果尾盘接近涨停：

```text
涨停封住：可以继续拿。
涨停反复打开：卖。
17.20 附近冲不动：卖。
17.50 附近封不住：卖。
```

为什么涨停反复打开要卖：

涨停打开说明卖盘很重。  
如果封单越来越少，第二天低开风险会变大。

### 第四步：最终四种处理

#### 情况 A：强势

条件：

```text
股价在 16.50 上方。
没有尾盘跳水。
有色板块不弱。
```

动作：

```text
冲涨停封住：继续持有。
冲涨停封不住：卖。
17.20 附近冲不动：卖。
```

#### 情况 B：正常

条件：

```text
股价在 15.76 附近或上方。
没有跌破 14.80。
成交没有明显砸盘。
```

动作：

```text
继续持有。
不加仓。
不买新股。
```

#### 情况 C：转弱

条件：

```text
跌破 14.80。
尾盘拉不回。
有色板块也弱。
```

动作：

```text
卖出或至少准备次日风险处理。
你只有一手，更简单：卖掉，保住纪律。
```

#### 情况 D：破位

条件：

```text
跌破 14.44。
```

动作：

```text
卖出认错。
不补仓。
不等反弹。
```
