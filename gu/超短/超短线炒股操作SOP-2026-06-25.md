# 超短线炒股操作 SOP：大师思想融合版

> 日期：2026-06-25  
> 定位：把巴菲特、利弗莫尔、欧奈尔、Minervini、Paul Tudor Jones、Linda Raschke、Marty Schwartz，以及 A 股超短高手的核心思想，转译成可执行的超短线训练系统。  
> 边界：这是交易训练框架，不推荐具体股票，不承诺收益，不替代持牌投顾意见。

## 0. 总纲

超短线不是“看到涨就追”，而是：

```text
巴菲特：只做能力圈内的机会
利弗莫尔：趋势证明你对，价格证明你错
欧奈尔：只做强势市场里的强势龙头
Minervini：先筛掉弱股，再等低风险买点
Paul Tudor Jones：先防守，亏损时缩手
Linda Raschke：盘前准备，盘中只执行
Marty Schwartz：用纪律把情绪关在门外
A股超短高手：看情绪周期、主线、龙头、退潮
```

一句话：

```text
先活下来，再做对；先少犯错，再谈赚钱。
```

## 1. 每位大师教你一件事

### 巴菲特：能力圈和安全边际

巴菲特不适合学超短买点，但适合学交易底层纪律。

转译成超短线：

```text
看不懂题材，不买。
看不懂公司，不买。
看不懂为什么涨，不买。
看不懂为什么该卖，不买。
没有安全边际，不买。
```

超短线的安全边际不是估值便宜，而是：

```text
买点不远
止损清楚
仓位很小
错了能退
次日低开也能承受
```

### 利弗莫尔：趋势和止损

利弗莫尔最值得学的是：不要和市场争辩。  
趋势证明你对，价格证明你错。

转译成超短线：

```text
突破后能站住，才算强。
回踩不破，才算有承接。
跌破关键位，不要幻想。
买入后不按预期走，说明判断可能错了。
```

利弗莫尔式纪律：

```text
先等市场给信号。
不要提前替市场做结论。
不要在亏损上加码证明自己对。
```

### 欧奈尔：只买强者

欧奈尔的核心不是“便宜”，而是“强”。  
强公司、强行业、强走势、强市场。

转译成 A 股超短：

```text
只看主线板块。
只看龙头或强二线。
不买弱股补涨。
不买下跌趋势里的便宜股。
大盘环境不好时，降低交易频率。
```

欧奈尔式过滤：

```text
市场方向不支持，不买。
板块不强，不买。
个股不是领导者，不买。
成交量不支持，不买。
```

### Minervini：先筛选，再等低风险点

Minervini 的核心是：不要在一堆烂票里找机会，先把弱的全部剔除。

转译成超短线：

```text
价格在关键均线下方，不看。
远离阶段高点太多，不看。
走势弱于板块，不看。
放量滞涨，不看。
买点离止损太远，不看。
```

Minervini 式买点：

```text
先有强趋势。
再有收缩整理。
再有放量突破。
最后才允许小仓试错。
```

### Paul Tudor Jones：先防守

Paul Tudor Jones 的重点是风险控制。  
交易做得差时，不是加倍努力下注，而是缩小仓位。

转译成超短线：

```text
连亏时减仓。
看不懂时空仓。
亏损后不补仓。
先保护本金，再追求利润。
```

PTJ 式防守：

```text
连亏 2 笔：停一天。
连亏 3 笔：下一笔减半。
连亏 5 笔：停一周。
```

### Linda Raschke：准备和节奏

Linda Raschke 值得学的是短线交易的准备工作、盘感训练和自我观察。

转译成超短线：

```text
盘前写计划。
盘中只执行。
盘后复盘。
每天训练同一种模式。
不要在盘中临时发明策略。
```

Raschke 式节奏：

```text
09:15-09:35 只判开局
09:35-10:30 只判承接
14:30-15:00 只判收盘态度
```

### Marty Schwartz：纪律比聪明重要

Marty Schwartz 的价值在于：交易员从混乱走向纪律。

转译成超短线：

```text
有计划才交易。
错了马上认。
情绪上头就停止。
每天打分，不靠感觉评价自己。
```

Schwartz 式纪律：

```text
赚钱但违纪，不算好交易。
亏钱但按计划执行，可以接受。
反复违纪，比单笔亏损更危险。
```

### A 股超短高手：情绪周期和龙头

A 股超短最核心的是情绪周期、主线和龙头。

转译成执行语言：

```text
冰点：不出手，观察新方向。
修复：小仓试错。
主升：只做主线龙头。
高潮：持仓止盈，新仓谨慎。
退潮：只卖不买。
```

## 2. 金牌交易员的工作流

普通人：

```text
看到涨 -> 兴奋 -> 追
看到跌 -> 害怕 -> 割
又涨了 -> 后悔 -> 再追
```

金牌交易员：

```text
先判情绪周期
再判主线板块
再判龙头地位
再判交易模型
最后才决定仓位
```

顺序不能反。

## 3. 情绪周期：A 股超短的总开关

### 冰点

特征：
- 涨停少。
- 跌停多。
- 昨日涨停今天低开多。
- 高位股补跌。
- 热门板块持续性差。

动作：

```text
不追高
不打板
不做后排
只观察新主线苗头
仓位 0%-20%
```

### 修复

特征：
- 指数止跌。
- 高位亏钱效应缓和。
- 新题材开始试探。
- 前期强势股不再大跌。

动作：

```text
小仓试错
优先看最早走强的核心股
不重仓
仓位 10%-30%
```

### 主升

特征：
- 主线清楚。
- 龙头持续创新高。
- 板块内多股共振。
- 成交额放大。
- 断板后亏钱效应不大。

动作：

```text
只做主线
只做龙头或强二线
优先做回踩确认和分歧转强
仓位 30%-50%，新手不超过 30%
```

### 高潮

特征：
- 板块大面积涨停。
- 后排补涨很快。
- 群消息、短视频、热搜都在说。
- 个股高开越来越多。
- 成交额巨大，分歧变重。

动作：

```text
不追后排
不追一字板
持仓分批止盈
新开仓仓位减半
仓位开始收缩
```

### 退潮

特征：
- 龙头放量滞涨。
- 涨停股开板增多。
- 昨日涨停次日低开。
- 高位股集体回落。
- 炸板、跌停、大阴线增加。

动作：

```text
只卖不买
不做反包幻想
不亏损补仓
仓位 0%-20%
```

## 4. 只做三种交易模型

### 模型一：龙头分歧转强

思想来源：

```text
欧奈尔：只做领导者。
A股超短：主线龙头最有辨识度。
利弗莫尔：等趋势重新证明。
```

适合：
- 情绪处于修复或主升。
- 题材处于启动或发酵。
- 龙头没有破位。

买点：

```text
早盘出现分歧
没有跌破核心支撑
板块重新回流
龙头重新站上分时均线
成交量不是砸盘量
```

不买：

```text
只有个股拉，板块不跟
龙头已经放量滞涨
后排比龙头更活跃
题材已经高潮
```

卖点：

```text
转强失败，卖
跌破早盘低点，卖
板块回流失败，卖
龙头先破位，卖
```

### 模型二：强势股回踩确认

思想来源：

```text
Minervini：先强趋势，再低风险买点。
利弗莫尔：趋势没坏才继续。
Raschke：等待节奏，不冲动。
```

适合：
- 主线仍在。
- 个股短期趋势没有坏。
- 回调是缩量，不是砸盘。

买点：

```text
回踩 5日线、10日线、20日线、前高平台或日内支撑
回踩缩量
重新放量拉回
板块没有退潮
```

不买：

```text
回踩放量下跌
板块龙头破位
支撑位反复被击穿
买入价离止损太远
```

卖点：

```text
跌破支撑，卖
反弹无量，减
板块退潮，退
买入后 1-2 天不走强，退出观察
```

### 模型三：放量突破

思想来源：

```text
利弗莫尔：突破代表趋势确认。
欧奈尔：强势股常从整理区间突破。
Minervini：收缩整理后的突破更优。
```

适合：
- 横盘充分。
- 压力位清楚。
- 板块也有强度。

买点：

```text
整理 5-10 个交易日以上
突破压力位
成交量明显大于近期均量
收盘仍站上突破位
不是单股孤立上涨
```

不买：

```text
早盘直线突破太远
突破后立刻放量回落
板块不配合
上方套牢盘太近
当天已经高潮
```

卖点：

```text
跌回突破平台，卖
突破 3 天无继续强势，退出
放量长上影，减仓
冲高封不住，减仓
```

## 5. 仓位：PTJ 防守规则

先决定能亏多少，再决定买多少。

```text
单笔最大可亏金额 = 账户总资金 × 0.5%-1%
每股风险 = 买入价 - 止损价
可买股数 = 单笔最大可亏金额 / 每股风险
实际买入股数 = 向下取整到 100 股
```

示例：

```text
账户资金：20,000 元
单笔最大亏损：1% = 200 元
买入价：10 元
止损价：9.5 元
每股风险：0.5 元
可买股数：200 / 0.5 = 400 股
买入金额：4,000 元
```

新手限制：

```text
单股最大仓位：账户 10%
单日最多新开仓：1 只
冰点/退潮：不开新仓
修复：小仓
主升：按计划
高潮：减半
```

连亏处理：

```text
连亏 2 笔：暂停新开仓 1 天
连亏 3 笔：下一笔仓位减半
连亏 5 笔：停止实盘 1 周，只复盘
```

## 6. 卖出：利弗莫尔 + PTJ

### 第一优先级：逻辑失效

出现以下情况，不等价格：

- 龙头破位。
- 题材退潮。
- 个股跌破关键支撑。
- 买入后没有资金继续接。
- 原来的买入理由被证伪。

动作：

```text
能卖就卖
不能当天卖，标记为次日风险单
次日先处理风险，不加仓
```

### 第二优先级：价格止损

```text
跌破止损，不补仓
跌破止损，不下移止损
跌破止损，不找消息安慰自己
```

### 第三优先级：分批止盈

```text
+2R：卖 30%
+3R：再卖 30%，剩余仓位移动止盈
冲涨停封不住：卖
高位放量长上影：卖一部分
板块退潮：先减仓
```

说明：`1R = 买入价 - 止损价`。例如买入 10 元，止损 9.5 元，1R = 0.5 元，+2R 就是 11 元。

### 第四优先级：时间止损

```text
买入后 1-2 个交易日没有按预期上攻：减仓或退出
突破后 3 个交易日无法继续走强：退出观察
题材热度下降：退出观察
```

## 7. 盘中三段：Raschke 节奏训练

### 09:15-09:35：看开局，不交易情绪

只回答：

```text
今天是冰点、修复、主升、高潮，还是退潮？
```

动作：

```text
开盘 5 分钟不追
高开太多不追
低开破位不幻想
陌生股不临时买
```

### 09:35-10:30：看承接，不看热闹

强承接：
- 回踩缩量。
- 拉升放量。
- 分时均线附近能接住。
- 板块同步回流。

弱承接：
- 高开低走。
- 放量冲高回落。
- 龙头先走弱。
- 跌破支撑拉不回。

动作：

```text
只有三种交易模型触发才买
没有模型就看
不为参与感下单
```

### 14:30-15:00：看收盘态度

```text
尾盘站稳，才考虑持有或小仓买入
尾盘跳水，优先处理风险
涨停封不住，优先兑现
```

## 8. 下单前 30 秒

```text
我现在是在执行计划，还是在追情绪？
这只股票是主线龙头、强二线，还是后排跟风？
当前是冰点、修复、主升、高潮、退潮的哪一段？
买点属于三种模型里的哪一种？
这个买点是否在我的能力圈内？
止损价在哪里？
如果明天低开 5%，我还能不能接受？
这笔最多亏多少钱？
如果这笔亏了，我会不会想补仓？
```

任一问题答不上来，撤单。

## 10. 金牌交易员评分表

不要只按赚钱亏钱评价交易。先评价执行质量。

```text
是否计划内交易：20 分
是否只做三种模型：15 分
是否判断情绪周期：15 分
是否识别龙头/跟风：15 分
是否在能力圈内：10 分
仓位是否按亏损倒推：10 分
止损/止盈是否执行：10 分
是否复盘：5 分
```

评分解释：

```text
90 分以上：可复用交易
75-89 分：执行基本合格，细节需修正
60-74 分：有明显问题，下一笔降仓
60 分以下：违纪交易，暂停新开仓
```

核心原则：

```text
赚钱但违纪，不算好交易。
亏钱但完全按计划执行，可以接受。
反复违纪，比单笔亏损更危险。
```

## 12. 最小执行版

如果只保留 12 条：

1. 巴菲特：看不懂不买。
2. 利弗莫尔：跌破关键位不幻想。
3. 欧奈尔：只做强势市场里的强势股。
4. Minervini：先筛掉弱股，再等低风险买点。
5. PTJ：亏损时缩手，不加码。
6. Raschke：盘前计划，盘中执行，盘后复盘。
7. Schwartz：赚钱但违纪，不算好交易。
8. A 股超短：先判情绪周期，再判主线龙头。
9. 只做龙头分歧转强、强势回踩、放量突破。
10. 单笔最大亏损只允许账户 0.5%-1%。
11. 跌破止损不补仓、不下移止损。
12. 不复盘不交易。

## 13. 思想来源

- Warren Buffett: Berkshire Hathaway shareholder letters, especially 1986 and 1996 letters.  
  https://www.berkshirehathaway.com/letters/1986.html  
  https://www.berkshirehathaway.com/letters/1996.html
- Jesse Livermore / Edwin Lefevre: `Reminiscences of a Stock Operator`.
- William J. O'Neil: CAN SLIM / IBD methodology, focusing on market direction, leading stocks, technical action, and risk control.  
  https://www.investors.com/how-to-invest/investors-corner/stock-market-investing-ibd-methodology/
- Mark Minervini: Trend Template, VCP, low-risk entry, risk-first position sizing.
- Paul Tudor Jones: defensive risk control, reduce size when trading poorly, do not average losers.
- Linda Raschke: `Street Smarts`, short-term pattern preparation and disciplined execution.
- Marty Schwartz: `Pit Bull`, daily process, risk control, and emotional discipline.
