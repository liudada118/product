# 中医按摩手法数据采集与矫正模型技术调研

## 1. 背景与目标

当前目标是基于传感器采集推拿、按摩等中医手法过程数据，训练模型用于后续的手法识别、手法量化和手法矫正。

这类问题的关键不在于识别某一帧压力图，而在于理解一次完整手法过程。滚法、揉法、按法、推法等手法都具有连续性、周期性、节律性和空间轨迹特征。单帧压力只能表达瞬时接触状态，无法表达发力过程、卸力过程、节奏稳定性、压力中心移动和周期连贯性。

因此，数据集的基本样本单位应设计为“一段完整手法 episode”，再在 episode 内部标注周期、阶段和偏差类型。

## 2. 核心判断：手法不是一帧，而是时序过程

### 2.1 为什么不能只做单帧分类

单帧压力图最多能回答：

- 当前哪里受力；
- 当前压力大小是多少；
- 当前接触面积多大；
- 当前压力中心在哪里。

但它无法回答：

- 这次发力是否平滑；
- 是否突然加力或突然卸力；
- 节奏是否稳定；
- 频率是否符合专家手法；
- 压力中心轨迹是否符合手法路径；
- 一个周期内的峰值、谷值、加载速度、卸载速度是否合理；
- 新手和专家在连续动作上的差异。

所以，单帧适合作为基础特征，不适合作为最终训练样本。

### 2.2 推荐的样本结构

建议采用三层数据结构：

| 层级 | 单位 | 作用 |
|---|---|---|
| 原始层 | 连续传感器数据流 | 保存全部压力、力值、姿态、视频等原始信息 |
| Episode 层 | 一次完整手法片段，通常 5-15 秒 | 作为模型训练和评估的主要样本 |
| 周期/阶段层 | 一个周期或一个动作阶段 | 用于细粒度量化和矫正反馈 |

示例：

```text
一次滚法 episode，时长 10 秒
├── 第 1 个周期：加载 -> 峰值 -> 卸载 -> 回摆
├── 第 2 个周期：加载 -> 峰值 -> 卸载 -> 回摆
├── 第 3 个周期：加载 -> 峰值 -> 卸载 -> 回摆
└── ...
```

这种结构可以同时支持：

- 手法类型识别；
- 专家/新手区分；
- 标准/错误分类；
- 力度、频率、轨迹、稳定性量化；
- 实时矫正反馈。

## 3. 传感器采集方案

### 3.1 推荐采集通道

| 通道 | 作用 | 优先级 |
|---|---|---|
| 压力阵列 | 采集接触面积、压力分布、压力中心轨迹 | 高 |
| 单点/多点力传感器 | 采集整体力度、峰值力、平均力、力冲量 | 高 |
| IMU | 采集手腕、手掌、手臂姿态、角速度、动作方向 | 高 |
| 视频 | 用于人工标注、动作回放、模型校验 | 中高 |
| EMG 肌电 | 采集操作者肌肉发力状态 | 中 |
| 音频 | 辅助同步、节奏分析 | 低 |

如果第一阶段资源有限，建议最低配置为：

- 压力阵列或压力垫；
- 手部或腕部 IMU；
- 同步视频。

### 3.2 采样率建议

| 数据类型 | 建议采样率 |
|---|---:|
| 压力阵列 | 50-100 Hz |
| 力传感器 | 100-200 Hz |
| IMU | 100-200 Hz |
| 视频 | 30-60 FPS |

如果目标是手法识别和初步矫正，`50-100 Hz` 通常可用。  
如果目标是分析更细的发力曲线、加载速度和卸载速度，建议使用 `100-200 Hz`。

### 3.3 时间同步

多传感器必须统一时间轴。建议每条数据都包含：

```text
timestamp_ms
session_id
operator_id
subject_id
sensor_id
value
```

视频和传感器数据之间可以使用以下方式同步：

- 开始采集时做一次明显敲击或按压动作；
- 传感器端记录同步事件；
- 视频端记录同步动作；
- 后处理时对齐压力峰值和视频动作。

## 4. 数据集设计

### 4.1 数据集基本单位

每条训练样本建议定义为一个 episode：

```json
{
  "episode_id": "roll_001_0001",
  "technique": "rolling",
  "body_part": "lower_back",
  "operator_id": "expert_001",
  "operator_level": "expert",
  "subject_id": "subject_001",
  "duration_sec": 10,
  "sampling_rate_hz": 100,
  "quality_label": "standard",
  "error_labels": [],
  "sensor_files": {
    "pressure": "pressure.csv",
    "imu": "imu.csv",
    "video": "video.mp4"
  }
}
```

### 4.2 标签体系

不建议只标注“对/错”。更适合建立多维度标签。

| 标签维度 | 示例标签 |
|---|---|
| 手法类型 | 滚法、揉法、按法、推法、拿法、摩法 |
| 操作者水平 | 专家、熟练者、新手 |
| 整体质量 | 标准、基本合格、不合格 |
| 力度偏差 | 过轻、过重、忽大忽小 |
| 节奏偏差 | 过快、过慢、节奏不稳 |
| 轨迹偏差 | 偏移、打滑、方向错误 |
| 接触偏差 | 接触面积不足、局部压迫、接触不稳定 |
| 姿态偏差 | 塌腕、角度过大、动作僵硬 |
| 连贯性偏差 | 断续、突然加力、突然卸力 |

### 4.3 标注粒度

建议分三种标注粒度：

#### 1. Episode 级标注

用于判断整段手法：

- 这是什么手法；
- 是否标准；
- 主要错误类型是什么；
- 整体评分是多少。

#### 2. 时间段级标注

用于指出错误发生在哪一段：

```json
{
  "start_ms": 3200,
  "end_ms": 4600,
  "error_type": "force_too_high",
  "severity": 3
}
```

#### 3. 周期级标注

用于周期性手法，比如滚法、揉法：

```json
{
  "cycle_index": 12,
  "start_ms": 4800,
  "end_ms": 5220,
  "peak_force_n": 38.5,
  "frequency_bpm": 142,
  "center_shift_mm": 8.2,
  "quality": "standard"
}
```

## 5. 手法量化指标

### 5.1 力度指标

| 指标 | 含义 |
|---|---|
| 峰值力 | 单个周期或整段中的最大力 |
| 平均力 | 整段操作平均力度 |
| 最小力 | 周期谷值 |
| 力冲量 | 力对时间积分，反映总作用量 |
| 加载速度 | 从低力到峰值力的上升速度 |
| 卸载速度 | 从峰值力回落的速度 |
| 力度波动 | 力值标准差或变异系数 |

### 5.2 节律指标

| 指标 | 含义 |
|---|---|
| 频率 | 每分钟动作次数 |
| 周期时长 | 单个动作周期持续时间 |
| 周期稳定性 | 周期时长的标准差 |
| 峰值间隔稳定性 | 相邻峰值之间的时间波动 |
| 节奏漂移 | 前半段与后半段频率差异 |

### 5.3 空间轨迹指标

| 指标 | 含义 |
|---|---|
| 压力中心 COP | 压力分布的中心点 |
| COP 轨迹长度 | 压力中心移动距离 |
| COP 方向 | 压力中心主运动方向 |
| 接触面积 | 当前受力区域大小 |
| 接触面积稳定性 | 接触区域变化是否平稳 |
| 偏移距离 | 与专家模板轨迹的距离 |

### 5.4 姿态指标

| 指标 | 含义 |
|---|---|
| 手腕角度 | 腕关节屈伸、偏转角 |
| 手掌倾角 | 手掌相对受力面的角度 |
| 角速度 | 动作速度和摆动强度 |
| 加速度 | 手法冲击性和突然动作 |
| 姿态稳定性 | 姿态是否过度抖动 |

## 6. 模型路线

### 6.1 第一阶段：规则指标 + 传统机器学习

第一阶段建议不要直接做大模型，而是先把关键指标跑通：

- 峰值力；
- 平均力；
- 周期频率；
- 周期稳定性；
- 接触面积；
- 压力中心轨迹；
- 加载和卸载速度。

可使用模型：

- Random Forest；
- XGBoost；
- SVM；
- Logistic Regression；
- 简单 MLP。

适合目标：

- 判断力度是否过大；
- 判断频率是否合格；
- 判断节奏是否稳定；
- 生成可解释评分。

### 6.2 第二阶段：时序深度学习

当数据量增加后，可以使用时序模型处理完整 episode。

| 模型 | 适用场景 |
|---|---|
| CNN + LSTM | 压力图序列识别，空间 + 时间联合建模 |
| CNN + GRU | 类似 LSTM，参数更少 |
| TCN | 时序卷积，适合实时和长序列 |
| Transformer Encoder | 数据量较大时建模长时依赖 |
| CNN + Transformer | 压力阵列图像序列 + 长时序关系 |

如果输入是压力阵列：

```text
每一帧压力图 -> CNN 提取空间特征 -> LSTM/TCN/Transformer 提取时间特征 -> 分类/评分/偏差输出
```

如果输入是多传感器时序：

```text
压力特征 + IMU 特征 + 力值特征 -> 时序模型 -> 手法类型 + 质量评分 + 错误类型
```

### 6.3 第三阶段：专家模板对齐与矫正反馈

矫正模型不应只输出“错了”，而应输出偏差原因。

建议建立专家模板：

```text
专家标准手法模板
├── 力度区间
├── 频率区间
├── 周期曲线形态
├── 压力中心轨迹
├── 接触面积变化
└── 姿态变化范围
```

新手手法与专家模板比较时，可使用：

- DTW 动态时间规整；
- 周期峰值对齐；
- 归一化时间轴；
- 专家均值曲线 + 置信区间；
- 多专家模板聚类。

输出示例：

```text
本次滚法整体评分：72/100
主要问题：
1. 力度偏高，峰值力高于专家区间 24%
2. 频率偏慢，当前约 96 次/分钟，目标区间为 120-160 次/分钟
3. 节奏不稳定，周期时长变异系数偏高
4. 压力中心向外侧偏移，轨迹稳定性不足
```

## 7. 数据量规划

### 7.1 原型阶段

目标：验证采集链路、指标计算、基础识别。

建议：

- 选择 1-2 个手法，例如滚法、揉法；
- 专家 5-10 人；
- 新手 10-20 人；
- 每人每个手法采集 30-50 段；
- 每段 8-10 秒。

数据量：

```text
1 个手法：
专家 10 人 x 50 段 = 500 段
新手 20 人 x 50 段 = 1000 段
合计约 1500 段 episode
```

这个规模足够做第一版：

- 手法识别；
- 力度合格判断；
- 频率合格判断；
- 节律稳定性判断；
- 基础矫正提示。

### 7.2 产品初版阶段

目标：支持 3-5 种手法和多种错误类型。

建议：

- 每种手法 1000-3000 段有效 episode；
- 至少 30 名操作者；
- 每种手法包含专家、熟练者、新手；
- 每种错误类型至少 200-500 段；
- 包含不同体型、部位、压力垫位置和采集日期。

### 7.3 商用泛化阶段

目标：适应真实用户、真实场景和不同训练机构。

建议：

- 每种手法 5000 段以上；
- 操作者 50-100 人以上；
- 多名专家建立专家模板；
- 跨设备、跨采集批次、跨场景验证；
- 独立测试集必须按操作者划分。

### 7.4 重要提醒：滑窗不等于真实数据量

可以用滑动窗口增强训练样本，例如 10 秒数据切成多个 2 秒窗口。但评估时不能把同一个人的同一次采集切出来的窗口同时放入训练集和测试集。

正确划分方式：

- 按操作者划分训练集、验证集、测试集；
- 或按采集批次划分；
- 或按机构/场景划分。

错误划分方式：

- 随机按窗口划分。

随机按窗口划分会导致数据泄漏，模型准确率虚高，真实使用时效果明显下降。

## 8. 推荐落地路线

### 8.1 MVP 目标

建议第一版只做一个手法，例如滚法或揉法。

MVP 输出：

- 当前手法类型；
- 力度是否合格；
- 频率是否合格；
- 节奏是否稳定；
- 压力中心是否偏移；
- 一句可执行的矫正建议。

### 8.2 第一版数据采集设计

每段采集：

- 时长：8-10 秒；
- 采样率：100 Hz；
- 同步视频；
- 同步记录操作者、对象、部位、手法、专家评分。

建议数据量：

```text
手法：滚法
专家：10 人 x 50 段 = 500 段
新手：20 人 x 50 段 = 1000 段
总计：1500 段
```

### 8.3 第一版模型架构

推荐采用混合架构：

```text
原始传感器数据
  -> 预处理
  -> 周期检测
  -> 指标计算
  -> 规则评分 + 机器学习分类
  -> 矫正建议
```

后续再升级为：

```text
压力图序列 / 多传感器序列
  -> CNN / TCN / LSTM / Transformer
  -> 手法识别
  -> 质量评分
  -> 错误类型识别
  -> 个性化矫正建议
```

## 10. 风险与注意事项

### 10.1 专家标准不能只有一个人

中医手法存在流派和个体差异。专家模板建议来自多名专家，而不是一个专家。

可以建立：

- 专家均值模板；
- 专家置信区间；
- 不同流派模板；
- 不同身体部位模板。

### 10.2 标准区间比单一标准值更合理

手法不是工业机械动作，不应要求所有人完全一致。更合理的是用区间和稳定性判断：

```text
峰值力在合理区间内
频率在合理区间内
周期波动小于阈值
轨迹偏移小于阈值
```

### 10.3 矫正反馈要可解释

用户需要知道怎么改，而不是只知道分数。

不推荐：

```text
本次得分 62 分。
```

推荐：

```text
力度偏高，尤其在第 3-5 秒峰值过大。建议降低按压力度，并保持周期峰值更平稳。
```

### 10.4 医疗与安全边界

如果产品用于训练和教学，可以先定位为动作训练与量化评估工具。  
如果涉及诊疗建议、疾病治疗效果判断、禁忌症识别，需要额外考虑医疗器械合规、临床验证和风险管理。
