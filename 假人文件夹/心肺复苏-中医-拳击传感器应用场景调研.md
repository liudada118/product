# 心肺复苏、中医、拳击传感器应用场景调研

调研日期：2026-06-22

## 1. 总体结论

三个方向的产品价值和落地难度不同：

| 场景 | 落地优先级 | 数据确定性 | 商业价值 | 主要风险 |
|---|---:|---:|---:|---|
| 心肺复苏 CPR 训练 | 高 | 高 | 高 | 需要对齐培训标准和设备精度 |
| 拳击训练 | 高 | 中高 | 中高 | 力量估算和头部冲击数据需要谨慎表达 |
| 中医脉诊 | 中 | 中低 | 中高 | 标注难、验证难、不能直接做诊断宣称 |

推荐优先做“心肺复苏 CPR 训练假人传感器系统”，其次做“拳击训练传感器系统”，中医方向更适合先做“采集、回放、教学、科研标注平台”，不要一开始做 AI 诊断。

## 2. 心肺复苏 CPR 训练场景

### 2.1 场景价值

心肺复苏训练有明确标准，适合通过传感器做实时反馈、培训考核和复盘报告。核心价值不是展示复杂数据，而是让学员当场知道“按压是否达标、哪里错了、怎么改”。

适合客户：

- 急救培训机构
- 学校和企业安全培训
- 医院、急诊科、护理培训中心
- 红十字会、应急管理相关机构
- CPR 假人设备厂商

### 2.2 需要采集的数据

核心数据：

| 数据 | 说明 | 价值 |
|---|---|---|
| 按压深度 | 成人训练通常关注 50 mm 以上的有效深度 | 判断是否按得够深 |
| 按压频率 | 常用目标区间为 100-120 次/分钟 | 判断节奏是否正确 |
| 完全回弹 | 每次按压后是否完全释放 | 避免胸廓未回弹 |
| 按压中断 | 每次停顿时长和总停顿时长 | 判断流程是否流畅 |
| 手部位置 | 是否偏离胸骨中下段 | 纠正错误姿势 |
| 通气次数 | 人工呼吸次数、间隔、时机 | 支持完整 CPR 流程训练 |
| 通气量 | 是否过度通气或不足 | 提升训练真实性 |
| 疲劳趋势 | 深度、频率随时间是否下降 | 判断是否需要换人 |
| 学员身份 | 学员、课程、班级、考核记录 | 培训管理和追溯 |

可选数据：

- 肩肘腕姿态
- 手掌接触面积
- 身体重心变化
- 教练人工评分
- AED 操作步骤记录

### 2.3 传感器方案

方案一：假人内置压力和位移传感器

- 优点：深度、回弹、通气数据更准确。
- 缺点：需要改造假人结构。
- 适合：新产品、培训机构采购。

方案二：外挂胸前模块

- 优点：可兼容已有假人，成本较低。
- 缺点：固定方式、位移估算精度需要验证。
- 适合：旧假人升级、低成本市场。

方案三：手环或手套 IMU

- 优点：佩戴简单，能判断频率和动作节奏。
- 缺点：按压深度难以准确测量。
- 适合：低成本辅助训练，不适合作为严肃考核的唯一设备。

方案四：摄像头或深度相机

- 优点：可识别姿态、手位、身体动作。
- 缺点：受场地、光照、遮挡影响。
- 适合：教室大屏、多人训练分析。

### 2.4 渲染方式

实时训练界面应当简单、直接、低认知负担。

建议界面模块：

- 中央大号频率仪表：显示当前按压频率，例如 108/min。
- 深度柱状条：绿色表示达标，黄色表示过浅，红色表示过深或异常。
- 回弹提示灯：未完全回弹时立即闪烁提醒。
- 手位示意图：用胸部区域图显示偏上、偏下、偏左、偏右。
- 时间轴：记录按压、停顿、通气、换人。
- 训练得分：深度达标率、频率达标率、回弹达标率、中断时间。
- 教练大屏：多人并排显示，快速发现谁需要纠正。

训练结束报告：

- 总分
- 是否通过
- 平均按压深度
- 深度达标率
- 平均频率
- 频率达标率
- 回弹达标率
- 最长中断时间
- 总中断时间
- 疲劳曲线
- 主要问题和改进建议

### 2.5 有价值的功能

最高价值：

- 实时纠错
- 标准化考核
- 自动生成培训报告
- 教练端多人监控
- 兼容旧假人的低成本改造方案

次级价值：

- 学员历史成长记录
- 班级排行榜
- 课程数据统计
- 设备使用率统计
- 证书或考核系统对接

## 3. 中医脉诊传感器场景

### 3.1 场景价值

中医传感器最适合从“脉诊数字化”切入。该方向的核心价值不是直接替医生诊断，而是把传统脉诊中的寸、关、尺位置和轻、中、重不同按压力度下的脉搏波形记录下来，用于教学、科研、医生辅助记录和长期趋势观察。

适合客户：

- 中医院校
- 中医培训机构
- 中医科研团队
- 健康管理机构
- 中医设备厂商

### 3.2 需要采集的数据

核心数据：

| 数据 | 说明 | 价值 |
|---|---|---|
| 寸关尺三点波形 | 手腕三个采集位置的脉搏波 | 对应中医脉诊基础结构 |
| 不同压力下波形 | 轻取、中取、重取，或连续压力曲线 | 模拟医生不同按压力度 |
| 脉搏周期 | 单次脉搏周期和稳定性 | 分析节律 |
| 波峰幅值 | 主波、重搏波等波形特征 | 判断波形变化 |
| 上升沿和下降沿 | 波形变化速度 | 反映血流动力学特征 |
| 左右手差异 | 左右腕部脉象差异 | 支持对比分析 |
| 皮肤温度 | 腕部局部温度 | 辅助解释状态变化 |
| 采集压力 | 传感器施加在腕部的压力 | 保证数据可重复 |
| 医师标签 | 中医师对脉象的判断 | 训练模型和教学使用 |
| 现代指标对照 | 血压、心率、HRV、血氧等 | 做验证和相关性分析 |

重要上下文数据：

- 年龄
- 性别
- 身高体重
- 作息
- 运动
- 饮食
- 情绪
- 药物
- 既往病史
- 女性经期信息
- 采集时间
- 采集环境温度

### 3.3 传感器方案

方案一：三点压力传感阵列

- 对应寸、关、尺。
- 适合教学和标准化采集。

方案二：柔性压力传感片

- 贴合手腕曲面。
- 佩戴舒适，但一致性和标定要重视。

方案三：主动加压模块

- 通过机械结构或气囊控制压力。
- 可以稳定采集轻、中、重不同压力下的波形。

方案四：PPG + 压力组合

- PPG 采集血流变化，压力传感器记录按压条件。
- 适合健康管理，但和传统脉诊对应关系需要验证。

### 3.4 渲染方式

中医场景的渲染重点是“可解释、可回放、可标注”，不要只给一个健康分。

建议界面模块：

- 三通道同步波形：寸、关、尺并排展示。
- 压力-波形热力图：横轴时间，纵轴压力，颜色表示波形幅值。
- 轻中重三层视图：分别展示不同压力下的波形。
- 左右手对比：左手和右手的波形、幅值、节律差异。
- 趋势视图：一周或一个月的脉率、波形稳定性、左右差异变化。
- 医师标注界面：医生可圈选波形片段并添加脉象标签。
- 教学样本库：同一脉象标签下展示多个真实案例。
- 科研导出：支持 CSV、JSON、原始波形、采样率、压力、标签导出。

### 3.5 有价值的功能

最高价值：

- 中医教学标准化
- 脉象数据采集和回放
- 医师标注和病例归档
- 长期趋势观察
- 建立高质量脉象数据集

次级价值：

- 体质管理报告
- 与睡眠、心率、血压数据联动
- 个人健康趋势提醒
- 教学考试和样本练习

### 3.6 风险

- 医师之间对脉象标签可能不一致。
- 临床验证成本高。
- 如果宣称疾病诊断，可能涉及医疗器械监管。
- 传感器位置、压力、佩戴方式会显著影响数据。
- 需要大量高质量标注数据，不适合一开始就重度依赖 AI。

## 4. 拳击训练传感器场景

### 4.1 场景价值

拳击场景适合做训练反馈、游戏化挑战、教练辅助和会员成长档案。用户对速度、力量、连击、排行榜等反馈敏感，产品展示效果强，容易形成体验闭环。

适合客户：

- 拳击馆
- 健身房
- 私教工作室
- 运动康复机构
- 家用智能健身设备厂商
- 青少年体能训练机构

### 4.2 需要采集的数据

核心数据：

| 数据 | 说明 | 价值 |
|---|---|---|
| 出拳次数 | 单回合和总训练出拳数 | 训练量统计 |
| 拳速 | 峰值速度、平均速度 | 评估爆发力 |
| 冲击强度 | 拳套或沙袋压力、加速度、冲量估算 | 评估力量 |
| 出拳类型 | 直拳、摆拳、勾拳、刺拳 | 动作识别 |
| 左右手分布 | 左手和右手出拳次数、速度、力量 | 找短板 |
| 组合拳 | 1-2、1-2-3 等组合识别 | 训练技战术 |
| 命中位置 | 沙袋或靶位上的命中热区 | 纠正准确性 |
| 回手速度 | 出拳后回到防守位置的速度 | 判断技术质量 |
| 疲劳趋势 | 回合内和回合间速度、力量下降 | 调整训练强度 |
| 心率 | 训练负荷和恢复情况 | 体能评估 |

安全相关数据：

- 头部冲击次数
- 头部线加速度
- 头部角速度
- 单次冲击强度
- 一段时间内冲击累计暴露

注意：头部冲击数据只能作为风险暴露记录和训练管理参考，不能直接宣称“诊断脑震荡”。

### 4.3 传感器方案

方案一：拳套或绑带 IMU

- 优点：部署简单，适合个人训练。
- 缺点：力量只能估算，精度依赖算法和标定。

方案二：沙袋压力阵列

- 优点：能采集命中位置和冲击分布。
- 缺点：硬件成本更高，安装复杂。

方案三：脚底压力垫

- 优点：分析重心转移和发力链。
- 缺点：对普通用户感知价值不如拳速和力量直接。

方案四：摄像头姿态识别

- 优点：可分析动作轨迹、身体姿态、防守动作。
- 缺点：受遮挡、光照、场地影响。

方案五：头盔或牙套传感器

- 优点：可记录头部冲击暴露。
- 缺点：验证难度和合规要求更高。

### 4.4 渲染方式

拳击场景的渲染需要即时、刺激、可比较。

建议界面模块：

- 实时大数字：拳速、力量、连击数、回合时间。
- 沙袋热力图：显示命中区域和命中密度。
- 每拳时间轴：记录每一拳的类型、速度、力量。
- 左右手对比：左右拳速度、力量、频率、稳定性。
- 组合拳识别：自动识别常见组合拳。
- 回合报告：每回合出拳数、平均拳速、最大力量、疲劳下降。
- 排行榜：个人最好成绩、课程排行榜、门店排行榜。
- 教练端视图：多个学员并排监控。
- 安全视图：头部冲击次数和累计强度趋势。

### 4.5 有价值的功能

最高价值：

- 拳速和力量实时反馈
- 左右手短板识别
- 组合拳训练
- 训练报告和成长档案
- 拳馆会员留存和课程数据化

次级价值：

- 排行榜和挑战赛
- 教练课程管理
- 多人团课大屏
- 体能恢复建议
- 头部冲击暴露提醒

## 5. 通用数据架构建议

建议统一成四层数据模型，方便三个场景共用底层能力。

### 5.1 原始传感器数据

字段建议：

- timestamp
- user_id
- session_id
- sensor_id
- sensor_position
- sample_rate
- ax
- ay
- az
- gx
- gy
- gz
- pressure
- force
- temperature
- battery
- signal_quality

### 5.2 动作事件数据

CPR：

- compression
- recoil
- ventilation
- pause
- hand_position_error

中医：

- pulse_capture
- pressure_stage
- stable_wave_segment
- doctor_annotation

拳击：

- punch
- hit
- combo
- round_start
- round_end
- head_impact

### 5.3 特征指标数据

CPR：

- compression_depth

中医：

## 6. MVP 建议

### MVP 1：CPR 假人训练反馈系统

优先级最高。

必须做：

- 按压深度
- 按压频率
- 回弹判断
- 中断时间
- 实时纠错
- 训练结束报告

可以后续做：

- 通气模块
- AED 流程记录
- 教练端多人监控
- 培训证书系统对接

### MVP 2：拳击训练反馈系统

适合快速做演示和商业体验。

必须做：

- 出拳次数
- 拳速
- 力量估算
- 左右手对比
- 回合报告
- 排行榜

可以后续做：

- 沙袋命中热力图
- 组合拳识别
- 头部冲击暴露记录
- 教练端团课系统

### MVP 3：中医脉诊采集与教学平台

适合做长期数据资产。

必须做：

- 寸关尺三点采集
- 压力同步记录
- 波形回放
- 医师标注
- 案例归档
- 数据导出

可以后续做：

- 趋势分析
- 相似样本检索
- 教学考试
- 多医师一致性评估
- 与血压、HRV、睡眠数据关联

## 7. 最有价值的数据资产

如果要把项目做成长期壁垒，真正有价值的不是单次传感器读数，而是高质量、可复用、可验证的数据资产。

优先级排序：

1. CPR 标准动作数据集：不同学员、不同错误动作、不同假人、不同深度和频率。
2. 拳击动作数据集：不同拳型、速度、力量、命中位置、疲劳状态。
3. 中医脉象标注数据集：寸关尺、压力、原始波形、医师标签、现代健康指标对照。
